# Shareable corrected-note pattern

Keep a simple, non-personal project layout:

```text
notes-project/
|-- originals/              Unchanged source scans or photos
|-- sources/                Authorized course references
|-- prompts/                Versioned redraw instructions
|-- output/
|   |-- corrected-notes/    Final PNGs
|   `-- workbooks/          Rebuilt derivatives, if requested
`-- qa/                     Rendered pages and semantic checks
```

Useful style traits include white ruled paper, black marker, restrained accent
colors, large phone-readable text, a single corrected mental model, and one
short memory rule. Keep BEFORE and AFTER states visually separate.

Preserve every original. When an explanation or diagram changes, update each
affected derivative and its prompt or generator so the set remains consistent.
Never include a learner's name, local path, school account, or course-answer
content in a public style reference.
