# Contributing

Contributions are welcome when they remain reusable, privacy-safe, and
platform-conscious.

Before opening a pull request:

1. remove real personal information and replace it with synthetic examples;
2. do not include private course material or assessment answers;
3. keep Windows/macOS paths portable unless a skill is explicitly platform-only;
4. run `python scripts/privacy_scan.py`;
5. validate every changed skill and test every changed script;
6. keep new dependencies minimal and document why each one is needed.

Never attach a real profile vault, credential, token, account screenshot,
private browser capture, or conversation export to an issue or pull request.
